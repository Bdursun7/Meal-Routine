# V4.1 yerel çalıştırma

Ücretli Apple hesabı gerekmez. Ayrıntılı veritabanı notu `server/db/README.md` içindedir. Komutlar `server/` klasöründen çalışır.

## 1. Postgres (Docker, port 5433)

```bash
docker run --name mealroutine-postgres \
  -e POSTGRES_USER=mealroutine \
  -e POSTGRES_PASSWORD=mealroutine \
  -e POSTGRES_DB=mealroutine \
  -p 5433:5432 \
  -d postgres:16
```

Durmuş konteyner: `docker start mealroutine-postgres`

## 2. Şema `0001`–`0011`

```bash
cd server
cp .env.example .env
```

`.env` içinde:

- `DATABASE_URL=postgres://mealroutine:mealroutine@localhost:5433/mealroutine`
- `JWT_SECRET` en az 32 karakter. Boşsa sunucu açılmaz.
- `CORS_ORIGIN` iOS için boş. `*` kabul edilmez.
- `NODE_ENV=development` iken `POST /v1/auth/dev` açıktır. Üretimde `NODE_ENV=production`.

```bash
npm install
npm run migrate
npm start
```

Adres `http://localhost:8080`. Kontrol: `curl http://localhost:8080/health` ve `curl http://localhost:8080/ready`. `/metrics` yalnız localhost, `METRICS_TOKEN` yoksa.

`SENTRY_DSN` ve `METRICS_TOKEN` boş kalabilir.

## 3. Uygulama

Xcode’da **MealRoutine Local** şemasını seç. Bu şema `Config/Debug-Local.xcconfig` kullanır: API `http://localhost:8080`, Sign in with Apple / iCloud / Push / App Group yok.

Simülatörde çalıştır. Ortak evi sunucusuz denemek için Profil → Birlikte planla → **Test modu**. Tek cihaz ve sahte partner. Test modu kapalıyken uygulama yerel API’ye gider.

## 4. Google istemci kimliği

Google Cloud Console’da OAuth iOS istemcisi, bundle `com.mealroutine.app`.

- `server/.env` → `GOOGLE_CLIENT_ID_IOS`
- `Config/Debug-Local.xcconfig` → `GOOGLE_IOS_CLIENT_ID` ve `GOOGLE_REVERSED_CLIENT_ID`

Örnek: `123-abc.apps.googleusercontent.com` için tersi `com.googleusercontent.apps.123-abc`.

## 5. Fiziksel cihaz (isteğe bağlı)

Simülatör `localhost` görür. Telefon görmez.

HTTPS tünel:

```bash
cloudflared tunnel --url http://localhost:8080
```

Çıkan `https://…` adresini Local şemasının API tabanına yaz. Tailscale ile Mac’in `100.x` adresi ve `:8080` de olur. Local ATS yerel ağda düz HTTP’ye izin verir; telefon için HTTPS tünel daha güvenlidir.
